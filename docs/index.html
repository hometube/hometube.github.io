HomeTube

A self-hosted media library: download videos and music, subscribe to channels and podcasts, and play everything back offline — on your own hardware.

Get HomeTube

Desktop All-in-one: bundled server and UI, QR pairing. macOS · Windows Setup guide
Mobile Android app that pairs with your server over the LAN. APK Server & CLI Headless Bun server driven by the ht command. Source

Quick start

git clone https://github.com/hometube/hometube.github.io hometube
cd hometube
bash install.sh        # macOS/Linux: bun, deps, and the ht command
# Windows: pwsh install.ps1  (also installs ffmpeg, yt-dlp, Deno via winget)

ht init                # choose your data directory + default user
ht serve               # serve the library on your LAN (port 8000)
ht pair                # mint a one-time token to connect a device

Everyday CLI

ht download <url>                     # auto-detects video / music / playlist
ht download <playlist-url> -p "Chill" # download into a named playlist
ht songs / ht playlists / ht videos   # browse your library
ht export -o backup.ht               # portable backup (.ht archive)
ht settings set auto_download off    # disable pre-download on add

Requirements

  • Bun — installed automatically by the install scripts
  • yt-dlp, ffmpeg, and a JavaScript runtime for yt-dlp's newer extractors (Deno recommended) for downloads — install.ps1 installs all three via winget; on macOS install them with brew when the script reports them missing
Data lives in one directory (config at ~/.config/hometube/config.json); your whole collection exports to a single .ht archive.
